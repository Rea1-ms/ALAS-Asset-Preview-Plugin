# ALAS 素材预览

适用于 VS Code（代码编辑器）1.96及以上。打开 ALAS（自动化框架）衍生项目，在资产变量上悬停即可查看图片。

预览按 area（识别区域）裁剪，直接显示源素材路径。点击预览图或“打开原图”可在当前编辑器中打开对应图片。多帧与不同目录中的素材分别提供入口；没有素材的版本会保留原始名称并说明。

从扩展面板菜单选择“从 VSIX（扩展安装包）安装”，安装根目录 dist/vscode（安装包目录）内的新包。扩展自行解析静态定义，无需额外安装语言服务。

插件只读取源文件与图片，不导入或执行项目代码，不连接设备，不修改源图。图片在内存中裁剪并嵌入悬浮文档，不在游戏仓库生成缩略图。

支持普通导入、相对导入、重导出、导入别名、赋值别名和模块限定引用。动态路径、通配导入与运行时赋值暂不支持。要求图片为项目素材目录内的 PNG（无损图片），单图最多一千六百万像素；悬浮文档最多展示十六帧。

开发时在仓库根目录运行 pnpm test:vscode（解析和图片测试）、pnpm build:vscode（构建扩展）、pnpm test:vscode:host（真实扩展宿主测试）和 pnpm package:vscode（打包扩展）。宿主测试会使用缓存目录内的独立编辑器，不改变当前编辑器的安装状态。
