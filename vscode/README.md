# VS Code 扩展

适用于 VS Code 1.96及以上版本。在素材变量上悬停就能看到图片，点击预览图或“打开原图”可以打开对应的源文件。

## 用法

1. 从发布页下载 VS Code 安装包，或使用自己构建的扩展包。
2. 在扩展面板菜单中选择“从 VSIX 安装”，安装后按提示重新加载窗口。
3. 打开 ALAS 衍生项目，把鼠标放到素材变量上。
4. 点击图片或“打开原图”，在图片标签页查看源图。

扩展自带源码解析，不需要额外安装语言服务或类型检查工具。

## 预览说明

预览按 area 裁剪，显示原始素材路径、图片尺寸和识别坐标。多语言素材和不同模板帧会分别显示；没有素材的版本会保留原始名称并给出提示。

支持普通导入、相对导入、重导出、导入别名、赋值别名和模块限定引用。动态生成的图片路径、通配导入和运行时赋值暂不支持。

项目需要沿用 ALAS 的目录结构，包含 module/base/button.py 和 assets。图片必须是该项目 assets 目录内的 PNG，单张不超过32 MB、1600万像素。每次最多显示16张预览，小图最多放大3倍。

图片在内存中裁剪，不会在游戏目录里生成缩略图。扩展只读取代码和图片，不运行项目脚本，也不连接设备。目前支持本地文件，网页虚拟工作区暂不支持。

## 构建和测试

按[项目说明](../README.md#构建)安装依赖后，在仓库根目录运行：

```powershell
pnpm build:vscode
pnpm test:vscode
pnpm test:vscode:host
pnpm package:vscode
```

这四条命令分别用于构建、源码和图片测试、编辑器内测试、打包。也可以使用共享运行配置中对应的入口。

安装包放在 dist/vscode。编辑器内测试会下载独立的 VS Code 到 .cache/vscode-host，再检查悬浮预览和原图跳转；已有下载会直接复用。测试使用单独的配置和扩展目录。

具体测试结果见[验证记录](../VALIDATION.md)。
