# 资产悬浮预览

ALAS Asset Preview（自动化框架素材预览）适用于 PyCharm（开发工具）2026.3。鼠标停在资产变量上时，在快速文档中显示识别区域的裁剪图。普通引用、导入别名和赋值别名使用编辑器自身的引用解析；同名资源按实际导入来源查找。

插件按目录结构识别 ALAS（自动化框架）及其衍生项目，不需要填写项目名称或安装路径。资产声明的上级目录同时包含 module/base/button.py（按钮定义）和 assets（源素材目录）时，将最近的符合目录作为所属项目根目录。使用同类静态按钮定义的 SRC（崩铁自动化项目）也适用。

## 安装和使用

1. 在编辑器的“设置 → 插件 → 齿轮 → 从磁盘安装插件”中，选择仓库根目录 dist/pycharm（安装包目录）下本次生成的压缩包，按提示重新加载插件或重启编辑器。
2. 在设置中搜索“悬停时显示快速文档”，启用对应选项。英文选项是 Show quick documentation on hover（悬停时显示快速文档）。
3. 在业务代码中将鼠标停在资产变量上，也可按 Ctrl+Q（快速文档快捷键）查看。
4. 点击每张预览旁的“打开原图”，或直接点击预览图，在编辑器的图片标签页打开对应源图。不同服务器和模板帧分别打开各自文件。

例如，将鼠标停在 MAIN_GOTO_SECRET_SHOP（主界面到秘密商店入口）上，应显示不同素材目录下的多个模板帧，以及没有素材的版本提示。

每张预览直接显示源图相对于项目根目录的路径，不把文件夹名称解释成某个游戏的服务器。没有源图的版本保留定义中的原始名称。小图最多放大三倍；单次文档最多显示十六项，超过时显示总数。缺图、不支持的版本和非法识别区域都有明确提示。预览按源码中的静态定义展示全部版本，不推断当前运行账号选择了哪个服务器。

## 本地构建和验证

构建直接使用已安装编辑器的开发接口，不需要下载另一份编辑器或安装项目依赖。以下命令在仓库根目录运行，参数填写本机编辑器的安装位置。

```powershell
./pycharm/build.ps1 -IdeHome '编辑器安装目录' -Test
```

build.ps1（构建脚本）的 Test（验证开关）会编译插件与测试，并执行图片裁剪、像素对照、文档图片回调、分服提示和非法路径检查。输出包含安装包和本次构建目录。

再使用以下脚本启动独立、无界面的编辑器进程，验证资产定义、业务引用、导入别名、快速文档扩展注册和原生图片解析。脚本默认选用最近一次启用验证开关的构建，也可传入 BuildDirectory（本次构建目录）指定。

```powershell
./pycharm/check_in_ide.ps1 -IdeHome '编辑器安装目录'
```

check_in_ide.ps1（编辑器集成验证脚本）将配置、插件、索引和日志放入本次构建目录的独立子目录，不安装到正在使用的编辑器中。受限环境需要允许测试进程创建本机套接字锁。正式用例位于 pycharm/tests（插件测试目录），默认使用自行生成的静态定义和确定像素的图片，不依赖游戏检出目录。需要额外检查原项目时，构建脚本可传入 AssetRepository（原项目目录）。

构建和测试产物保存在根目录 .cache/pycharm（构建缓存目录），安装包保存在 dist/pycharm（安装包目录）。根目录的统一脚本与共享运行配置也可完成相同操作。

## 边界

插件只静态读取 ButtonWrapper（按钮包装）和 Button（按钮）的定义以及对应图片，不执行项目代码，也不连接设备。裁剪坐标来自 area（识别区域），因此同名属性覆盖和不同模板帧会沿用生成结果。插件不会修改源图或生成包装。

图片只缓存在内存中，重新请求文档时读取当前内容。声明所在目录决定仓库根目录，因此在多个工作树中可以分别预览。图片必须位于声明所属仓库的素材目录中，指向目录外的文件会被拒绝。

0.1.4（当前插件版本）直接从源码位置提供资产文档，裁剪后的图片以嵌入内容交给编辑器原生图片加载器。原图跳转使用文档的原生链接处理接口，在当前编辑器中打开，不启动外部浏览器。插件标识保持不变，可以覆盖升级之前安装的版本。安装新版后完整重启编辑器，再检查业务引用处的快速文档。此功能不需要 ty（类型检查器）或 ruff（代码检查器）。

本次版本只声明兼容编辑器的 263（2026.3 构建系列）；其他版本需要重新核对接口。构建目录和安装包目录均已被仓库既有忽略规则排除。所有构建、测试日志与旧安装包保留，完成后可由用户手动清理。

## 已验证范围

旧版0.1.1的实际编辑器日志确认：私有图片协议被原生加载器以“未知协议”拒绝，因此弹窗有文字而图片一直转圈。新增检查已在旧版复现同一失败；当前版本改用原生支持的嵌入图片，并检查编码后的图片像素。

验证包含真实秘密商店引用、导入与赋值别名、用户反馈的免费召唤活动资产、源码位置入口、原生图片地址解析、指针恢复和原图链接。无界面编辑器的文件管理器默认只处理文本，图片跳转检查通过其专用接口选择随编辑器提供的真实图片编辑器；不使用模拟图片编辑器替代。

2026年11月13日在本机263.7307.206（编辑器构建版本）上验证0.1.3（迁出前版本），完成20项图片与文档检查、43项编辑器集成检查，全部通过。通过原生文档链接入口打开了用户反馈的领奖素材，并确认创建的是对应源文件的真实图片编辑器；国服、国际服和第二模板帧的跳转路径也分别通过检查。

集成验证还创建了独立的同类项目，使用与当前仓库同名的资产及不同语言目录，确认预览显示原始素材路径、没有素材的版本保留原始名称，原图入口指向声明所属项目的文件。测试项目只在本次构建目录生成，不修改其他项目。

用户提供的截图已确认0.1.2（上个插件版本）能在 SRC（崩铁自动化项目）显示两帧预览和原图入口。本次没有安装到用户当前窗口，也没有运行游戏、配置生成器或游戏离线回归。

迁出后的0.1.4（当前插件版本）已改用独立生成的素材和项目结构，20项图片与文档检查、43项编辑器集成检查全部通过。多帧定义同时覆盖括号包裹的元组，构建与测试不再依赖原游戏目录。
