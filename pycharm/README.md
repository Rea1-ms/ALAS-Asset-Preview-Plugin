# PyCharm 插件

适用于 PyCharm 2026.3。在素材变量上悬停就能看到图片，点击预览图或“打开原图”可以打开对应的源文件。

## 用法

1. 从发布页下载 PyCharm 安装包，或使用自己构建的压缩包。
2. 在“设置 → 插件 → 齿轮 → 从磁盘安装插件”中选择压缩包，安装后重启。
3. 开启“悬停时显示快速文档”，把鼠标放到素材变量上；也可以按 Ctrl+Q。
4. 点击图片或“打开原图”，在图片标签页查看源图。

之前安装过旧版的话，直接覆盖升级即可。

## 预览说明

支持 ButtonWrapper 和 Button 中的静态素材定义。普通导入、导入别名和赋值别名都能查看，同名变量按实际导入来源查找。

预览按 area 裁剪，显示原始素材路径、图片尺寸和识别坐标。多语言素材和不同模板帧会分别显示；没有素材的版本会保留原始名称并给出提示。

每次最多显示16张预览，小图最多放大3倍。图片需要是项目 assets 目录内的 PNG，单张不超过1600万像素。缺图或裁剪坐标无效时，悬浮窗会说明原因。

插件会从素材声明所在位置向上查找同时包含 module/base/button.py 和 assets 的目录，用它确定项目位置。沿用这套结构的 ALAS 衍生项目都可以使用，不需要填写游戏名称或项目路径。

图片在内存中裁剪和缓存。插件只读取源文件，不运行项目脚本，也不连接设备，不需要额外安装 ty 或 ruff。

## 构建和测试

在仓库根目录运行，先把 PyCharm 的安装位置填好：

```powershell
$env:ALAS_PREVIEW_IDE_HOME = '你的 PyCharm 安装目录'
pnpm build:pycharm
pnpm test:pycharm
```

依赖安装方式见[项目说明](../README.md#构建)。也可以使用共享运行配置里的“开发工具插件：构建”和“开发工具插件：测试”。

安装包放在 dist/pycharm，构建、测试项目和日志放在 .cache/pycharm。测试会自行生成素材，再启动独立的 PyCharm 检查悬浮预览和原图跳转，不依赖游戏仓库。

底层脚本使用本机 PyCharm 的开发接口，不会另行下载编辑器。目前只适配2026.3构建系列，其他版本尚未验证。

具体测试结果见[验证记录](../VALIDATION.md)。
